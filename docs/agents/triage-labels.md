# Triage Labels

技能以五个规范分诊角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库标签 | 含义 |
| -------------------------- | ---------- | ---- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估此 issue |
| `needs-info`               | `needs-info`       | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`  | 已完整定稿，可供 AFK agent 认领 |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现 |
| `wontfix`                  | `wontfix`          | 不会处理 |

当技能提到某个角色（如"应用 AFK-ready 分诊标签"），使用本表对应列中的标签字符串。

若想要不同词汇，编辑右列以匹配实际使用的命名。
