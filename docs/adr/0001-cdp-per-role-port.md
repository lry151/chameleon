# 每个角色通过独立 CDP 调试端口受工具控制

工具需要读取角色窗口当前激活标签页的 URL（接力的地基）、优雅关闭窗口、设置窗口位置、枚举标签页（快照）——这些能力只有 Chrome DevTools Protocol 提供。决定：每个角色启动时携带唯一 `--remote-debugging-port`（创建角色时自动挑选空闲端口并存入配置），工具通过 chromiumoxide 连接、常驻驱动。

不使用 CDP 则接力退化为让用户手动复制 URL，快照、窗口位置记忆、一键关闭全部不可实现。

**Consequences**: 每个角色窗口会开一个仅 localhost 可访问的调试端口——任何本机进程理论上可控制测试浏览器，对纯内网手工测试工具可接受。Chrome 要求使用非默认 `--user-data-dir` 才能开启远程调试——与角色的隔离设计天然一致。
