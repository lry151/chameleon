# 端口占用语义：接管成功则接管，连接失败则硬错误

角色启动时若其持久化 CDP 端口已被占用：先 `Browser::connect` 接管——成功 = 该角色上次崩溃残留的 Chrome，接管复用（崩溃恢复，ADR-0001 常驻驱动精神）；连接失败 = 端口被非浏览器或僵尸实例占用，硬错误并中文提示「请一键关闭所有后重试」，不再 fall-through 到 `Browser::launch`。原 fall-through 在占用的端口与锁定的数据目录上反复 spawn 瞬时窗口，是「几个窗口一直闪」的可疑根因。

**Considered Options**: 自愈重分配（挑新端口 + 持久化 + 重发）——否决，僵尸实例仍锁 `--user-data-dir` 时新端口照样启动失败，且静默改 `cdp_port` 有意外性。

**Consequences**: 合法崩溃恢复接管保留；端口被外部占用时用户「一键关闭 → 重试」两步解决，零静默副作用。
