# 快照恢复 = 对齐快照内角色，非整体状态回滚

快照恢复只对快照中存在的角色做标签页与窗口位置对齐（打开快照标签、关闭多余旧标签）；快照后新增的角色不被关闭，快照后删除的角色静默跳过，沙箱完全不碰。不采用「真正全量恢复」——那会在手工测试中误杀用户当前打开的窗口，破坏性且意外。恢复时抑制该角色的 auto_open 预设（避免默认页与快照页叠加），并保留角色首页锚点页签（纳入 close_other_tabs 的 keep 集合）以维持窗口标题可辨。快照仅记录测试标签页，过滤 chameleon 内部占位页签（role-home data URL）。

**Considered Options**: 真正全量恢复（关闭快照外角色与沙箱、回到快照整体状态）——否决，误杀当前窗口、破坏性。

**Consequences**: 「恢复到指定快照」是术语便利而非字面回滚；快照外的运行角色保持原状。按单窗口角色建模——用户手动开的第二窗口位置不入快照。
