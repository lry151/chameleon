# chameleon（变色龙）需求基线（已确认）

来源：用户整理的需求清单 + 2026-08-05 grilling 会话决议。术语见 `CONTEXT.md`。

## 一、核心需求

### 1.1 会话隔离管理

- 隔离粒度：每个角色对应独立 Chrome 用户数据目录（`--user-data-dir`），完全隔离 Cookie / LocalStorage / SessionStorage / HTTP 缓存 / Service Worker 缓存，与手动启动独立 Chrome 实例效果一致
- 零谷歌依赖：创建/使用全程无需登录 Google 账号，纯本地运行
- 自动检测 Chrome 路径（注册表 App Paths / PATH / 常见安装目录），失败支持手动指定；Edge（Chromium 内核）作为备选浏览器进 v1（同参数，仅路径检测差异）
- 可视化区分：角色自定义名称（如「ERP-管理员」）+ 颜色标识，界面醒目色块展示
- 安全兜底：禁止覆盖 Chrome/Edge 默认主配置目录，所有测试数据目录默认存放于软件专属目录

### 1.2 Handoff 会话接力

- 触发：在角色 A 窗口点「接力」→ 工具列出当前激活标签页 URL + 目标角色，两个按钮：
  - **并行打开**：保留 A，在 B 新标签页打开 URL，聚焦 B
  - **接力打开**：CDP 优雅关闭 A，在 B 新标签页打开 URL，聚焦 B
- 目标角色已启动则直接开标签页，未启动则先拉起再打开
- 传递内容 v1 仅当前激活标签页 URL；全部标签页 / 滚动位置为增强项，不进 v1
- 目标角色未登录时看到登录页属预期行为（这正是权限差异验证的目的）

### 1.3 零技术门槛交互

- 所有操作均为按钮点击，无命令行输入
- 自然语言错误提示，如「未找到 Chrome，请点击『选择 Chrome 路径』手动指定」
- 「一键启动所有预定义角色窗口」「一键关闭所有测试用 Chrome 窗口」（CDP 优雅关闭，仅测试数据目录）
- 角色配置导出/导入（拷贝 config.json），新人入职直接导入

## 二、衍生需求（v2）

- **会话快照/恢复**：某时刻所有角色打开标签页 URL + 窗口位置的 JSON 记录，一键恢复
- **临时沙箱**：用完即删的一次性隔离窗口。机制：工具监听沙箱 Chrome 进程退出 → 删除临时数据目录；每次工具启动扫描并清理崩溃残留的孤儿临时目录
- **数据目录清理**：一键清理所有测试用临时数据目录

## 三、v1 裁剪线（已确认）

- **v1**：核心 1.1 / 1.2 / 1.3 + 常用 URL 预设（点击即打开）+ 窗口位置记忆（CDP setWindowBounds 或 Chrome 自带记忆）
- **v2**：会话快照/恢复 + 临时沙箱 + 数据目录清理

## 四、非功能需求

- 完全离线可用；优先 Windows（国内测试团队主流），macOS/Linux 可选
- 工具启动 < 2s，启动单个 Chrome 实例 < 3s
- 所有配置、会话数据仅存本地明文 JSON，不上传云端
- 不误删默认配置；失败自动回滚；config.json 明文可人工修改

## 五、明确排除

- ❌ 账号同步（无需登录任何云服务）
- ❌ 浏览器指纹隔离（仅会话级隔离）
- ❌ 自动化测试能力（不替代 Playwright，仅服务手工测试）
- ❌ 权限配置/用户管理体系（工具本身无需登录）
- ❌ Chrome 扩展级别的隔离
