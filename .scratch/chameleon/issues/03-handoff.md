# 03 — Handoff 会话接力

**What to build:** 在角色 A 的窗口点「接力」→ 工具读取当前激活标签页 URL → 选择目标角色 → 「并行打开」（保留 A，B 新标签页打开并聚焦）或「接力打开」（CDP 优雅关闭 A，B 新标签页打开并聚焦）；目标角色未启动时自动先拉起再开标签。

**Blocked by:** 01 — 骨架 + 角色创建 + 首个隔离窗口

**Status:** ready-for-agent

- [ ] 接力后目标角色窗口出现对应 URL 的新标签页并聚焦
- [ ] 并行模式保留 A 窗口，双窗口并排对比
- [ ] 接力模式优雅关闭 A 窗口（非强制 kill）
- [ ] 目标角色未启动时自动先拉起再开标签
- [ ] 目标角色未登录时显示登录页属预期（不视为失败）
